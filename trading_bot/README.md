# 🤖 MT5 Trading Bot - بوت التداول الآلي

بوت تداول احترافي متكامل يتصل بـ MetaTrader 5 ويحلل السوق بـ **19 مؤشر فني** ويفتح ويدير الصفقات تلقائياً.

---

## 🚀 التشغيل السريع

```bash
# تحليل فقط (بدون صفقات حقيقية)
python trading_bot.py --dry-run --goal 20

# تداول حقيقي بهدف $20
python trading_bot.py --goal 20

# تداول بمخاطرة 1.5% وهدف 20%
python trading_bot.py --risk 1.5 --goal-pct 20

# إغلاق كل الصفقات المفتوحة
python trading_bot.py --close-all
```

**أو بضغطة واحدة:**
- `run_dry.bat` → تشغيل بدون صفقات (للاختبار)
- `run_bot.bat` → تشغيل كامل

## 📈 الاستراتيجيات (4 استراتيجيات)

1. **Trend Following** - متابعة الاتجاه
   - الدخول عند: EMA20 > EMA50 > EMA200 + ADX > 25 + MACD إيجابي

2. **Mean Reversion** - الارتداد للمتوسط
   - الدخول عند: السعر تحت/فوق نطاقات بولينجر + RSI في منطقة التشبع

3. **Breakout** - الاختراق
   - الدخول عند: اختراق القنوات الدونشيانية مع حجم مرتفع

4. **MACD Divergence** - الاختلاف
   - الدخول عند: تباين بين السعر وـ RSI + تحول هيستوجرام MACD

## ⚙️ خيارات التشغيل

```
--goal X        هدف الربح بالدولار
--goal-pct X    هدف الربح كنسبة مئوية
--dry-run       تحليل فقط بدون تداول
--risk X        نسبة المخاطرة لكل صفقة (%)
--symbols X,Y   رموز مخصصة (مثل: XAUUSDm,BTCUSDm)
--interval X    وقت الفحص بالثواني (افتراضي: 60)
--max-pos X     أقصى عدد صفقات مفتوحة
--close-all     إغلاق كل الصفقات والخروج
```
